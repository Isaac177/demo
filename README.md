# Telegram GREEN-API Chat

Веб-приложение на React для отправки и получения текстовых сообщений Telegram через GREEN-API.

## Возможности

- подключение по данным инстанса GREEN-API
- создание чата по номеру телефона получателя
- отправка и получение текстовых сообщений
- отображение статуса отправленных сообщений
- интерфейс на русском и английском языках
- адаптивная верстка

## Локальный запуск

Требования: Node.js 20 или новее и npm.

```bash
git clone https://github.com/Isaac177/demo.git
cd demo
npm install
npm run dev
```

После запуска приложение будет доступно по адресу [http://localhost:4174](http://localhost:4174).

## Подключение

1. Создайте инстанс Telegram в личном кабинете GREEN-API.
2. Включите получение входящих уведомлений и уведомлений о статусах отправленных сообщений.
3. Откройте приложение.
4. Введите `idInstance`, `apiTokenInstance` и `apiUrl` из настроек инстанса.
5. Укажите номер получателя в международном формате и создайте чат.

Секретные данные не хранятся в репозитории. Они вводятся пользователем при подключении и сохраняются только в текущей сессии браузера.

## Проверка проекта

```bash
npm run verify
```

Команда запускает линтер, тесты, проверку архитектуры, проверку локализации и production-сборку.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы создаются в каталоге `dist`.

## Развертывание на Netlify

Настройки сборки и перенаправление маршрутов SPA находятся в `netlify.toml`. При подключении репозитория Netlify использует команду `npm run build` и публикует каталог `dist`.
