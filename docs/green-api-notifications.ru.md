# Настройка уведомлений GREEN-API

Чтобы приложение получало ответы и статусы сообщений, откройте настройки Telegram-инстанса в личном кабинете GREEN-API.

Проверьте следующие параметры:

- поле `webhookUrl` пустое;
- включены уведомления о входящих сообщениях;
- включены уведомления о сообщениях, отправленных через API;
- включены уведомления о сообщениях, отправленных с телефона;
- включены уведомления о статусах отправленных сообщений.

Сохраните настройки и подождите около минуты. После этого создайте диалог в приложении заново и отправьте тестовое сообщение.

Приложение получает события методами `ReceiveNotification` и `DeleteNotification`. Отдельный сервер для локальной проверки не нужен. В рабочем проекте лучше использовать серверный webhook, чтобы не хранить ключ API в браузере и получать события при закрытой странице.
